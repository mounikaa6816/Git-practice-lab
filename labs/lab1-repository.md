# Lab 1: Repository

## Objective
Learn what a Git repository is and create your first GitHub repository.

## Theory
A repository (repo) is a storage location where Git tracks files and their changes over time.

## Tasks Completed
- Created a GitHub repository
- Added a README.md file
- Made the first commit

## Key Points
- A repository stores project files.
- Git tracks all changes inside a repository.
- A repository can be Public or Private.

## Commands
No Git commands were used in this lab because the repository was created using the GitHub website.

## Outcome
Successfully created my first GitHub repository.
