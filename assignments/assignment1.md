# Assignment 1 - Basic Git Workflow

## Objective

Practice the basic Git workflow from creating a file to pushing it to GitHub.

## Tasks

- [x] Create a GitHub repository
- [x] Clone the repository
- [x] Create `hello.txt`
- [x] Check repository status
- [x] Stage the file using `git add`
- [x] Commit the changes
- [x] Push the changes to GitHub

## Commands Used

```bash
git clone
git status
git add
git commit
git push
```

## Outcome

Successfully completed the basic Git workflow.
